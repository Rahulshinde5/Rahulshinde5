**Technical highlights**

* Processed 216 monthly observations across the master dataset.
* Transformed 11,232 mortgage delinquency records.
* Created a DuckDB analytical layer with reusable KPI queries.
* Automated data ingestion, transformation, validation, and KPI generation.
* Integrated Claude tool calling to route business questions to predefined analytical tools.

**Architecture principle:** Python and DuckDB calculate the numbers; Claude interprets the question and explains the results.

**Technology:** Python · SQL · Pandas · DuckDB · Streamlit · Claude API · CFPB public data
