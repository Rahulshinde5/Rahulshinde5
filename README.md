## 🚀 Featured Project

### 🏦 AI-Powered Mortgage Lending & Credit Risk Intelligence Platform

An automated fintech analytics platform that combines public mortgage data, a SQL analytics layer, interactive visualizations, and a Claude-powered AI analyst.

<p align="center">
  <a href="https://mortgage-risk-ai.streamlit.app/">
    <img src="https://img.shields.io/badge/OPEN_LIVE_DASHBOARD-Visit_App-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white" alt="Open live dashboard"/>
  </a>
  <a href="https://github.com/Rahulshinde5/mortgage-risk-ai">
    <img src="https://img.shields.io/badge/EXPLORE_CODE-View_Repository-181717?style=for-the-badge&logo=github" alt="Explore source code"/>
  </a>
</p>

**What it does**

* 📈 Tracks mortgage originations, dollar volume, and delinquency trends.
* 🏦 Analyzes mortgage performance across 30–89 days past due and 90+ days past due.
* 🔍 Examines mortgage dollar-volume distribution across borrower FICO-score groups.
* 🤖 Uses Claude tool calling to interpret business questions, select analytical tools, retrieve calculated results, and explain insights in natural language.
* ⚙️ Connects data ingestion, transformation, KPI computation, validation, storage, and dashboard visualization in an automated workflow.

**Technology stack**

`Python` `SQL` `Pandas` `DuckDB` `Streamlit` `Claude API`

**Architecture**

`Public CFPB Data → Python ETL → Data Validation → DuckDB → KPI Layer → Streamlit Dashboard → AI Analyst`

**Selected insights from the latest available dashboard snapshot**

* Mortgage originations: **477,971** in December 2025, up 17.75% year over year.
* Mortgage origination volume: **$188.95 billion**, up 27.08% year over year.
* 30–89 DPD rate: **2.1%**.
* 90+ DPD rate: **0.9%**.

<details>
  <summary>🧠 How the AI analyst works</summary>

1. A user asks a business question in natural language.
2. Claude interprets the question and selects an available analytical tool.
3. Python and DuckDB perform the numerical calculations using the underlying data.
4. Claude turns the returned results into a business-friendly explanation.

**Design principle:** Python and DuckDB provide the numerical truth, while Claude provides the reasoning and business explanation.

  </details>
